# Asset Archive

This directory retains superseded experiments that are useful for visual
comparison but are not authoritative and must not be imported by the app.

- `runtime-prototypes/` contains the previous flat `hero` and `town` sprite
  trials.
- `cinematic-media/` contains superseded ambient and interaction encodes that
  were removed from `public` so they are no longer deployed.

Promote an archived asset only by copying it into a versioned model-library
package, validating it there, and regenerating the corresponding runtime asset.
